Get around

Opening Crossway, moving through items, and completing a selection.

Switch apps

Hold ⌘ and press Tab to open the app row. Press Tab again to select another app. Release ⌘ to switch to the selected app. Its windows appear below the row after the preview delay.

Default
⌘ Tab

Quick tap

Press and release a shortcut before the show delay to switch without displaying the interface. A quick ⌘ Tab returns to the previous app. A quick ⌘ ` activates the front app's previous window.

Where

Holding the shortcut

Hold a shortcut past the show delay to display Crossway. The default show delay is 0.10 s. The app row's window strip appears after a further 0.40 s; the window shortcut displays its strip immediately. The grid has its own show delay, also 0.10 s by default, measured from the keypress.

Default
Show delay 0.10 s, window preview show delay 0.40 s, exposé show delay 0.10 s
Settings
General → Previews → UX presets (Fluid, Fast, or Custom), Switcher show delay, Window preview show delay, Exposé show delay
Status
Always Timing is adjustable

See also Preview timing in the Settings reference.

While the switcher is open

Keyboard and pointer controls available during a switching session.

Session modifiers

The letter commands below use the modifiers from the shortcut that opened Crossway. Their tables show ⌘, the default modifier. If Switch apps is set to ⌃ Tab, ⌃ W uses the same modifier during that session. Esc and the arrow keys require no modifier.

Where
App row, window strip, grid
Status
Always

Esc

Press Esc to dismiss Crossway without activating the selected item. Esc also resets a sequence of quick ⌘ ` presses.

Key
Esc
Where
App row, window strip, grid
Status
Always

Arrow keys

The arrow keys move the selection while Crossway is open. The keys are not passed to the active app.

  • App row: ← and → move through apps and wrap at the ends. In a multi-row layout, ↑ and ↓ move between rows. From the bottom row, ↓ opens the selected app's window strip.
  • Window strip: ← and → select the previous or next window. ↑ returns to the app row. ↓ has no effect.
  • Grid: all four arrows move between tiles and stop at the grid's edges. Press the grid shortcut again to select the next tile and wrap.
Keys
← → ↑ ↓
Where
App row, window strip, grid
Status
Always

Live previews

When live previews are enabled, each tile changes from a still to a live feed after the preview settles. A master switch controls the feature, with separate switches for the app switcher and grid. Disabled surfaces continue to display stills. macOS shows its purple recording indicator while live feeds are active.

Where
Window strip, grid

Background capture

Background capture refreshes stills between sessions: when you switch apps, switch to another window of the same app, change Spaces, wake or unlock the Mac, connect a display, change the system appearance, or open a window in the front app. Moving between windows of one app captures the window you just left. Crossway does not capture while the screen is locked, and window pixels are not written to disk. When this setting is off, capture occurs only while Crossway is open.

Settings
Optional → Previews → Background capture
Status
On by default Optional

See also Memory-only window captures.

Minimized windows

Minimized windows remain available in the window strip and grid. Their tiles display the last still, or the app icon, with a Minimized label. Crossway can capture a still of a minimized window but cannot provide a live feed. Activating the tile restores the window from the Dock. Turn off Include minimized windows to omit them.

Where
Window strip, grid

Native window cycling

When Native window cycling is off, quick ⌘ ` presses alternate between the app's two most recent windows. When it is on, quick presses move through every window in the selected window order; add ⇧ to move in reverse. Most recently focused order is updated when previews appear. Alphabetical and macOS window order remain fixed. The same rules apply to quick presses of Focused app's windows.

Settings
General → Ordering → Native window cycling
Status
Off by default Optional

See also Order of windows and Quick tap.

Privacy, permissions, and data

Permissions, window capture, local storage, and network access. See the shorter Privacy summary on the homepage.

Accessibility permission

Accessibility permission lets Crossway intercept its shortcuts and activate the selected app or window. Grant it in System Settings → Privacy & Security → Accessibility. Crossway detects the grant without restarting.

Where
System Settings → Privacy & Security → Accessibility
Status
Always Required

See also Guided setup.

Screen Recording permission

Screen Recording permission lets Crossway capture window stills and live feeds. Without it, tiles display app icons only. Grant it in System Settings → Privacy & Security → Screen Recording. Crossway relaunches once after the permission is granted, as required by macOS.

Where
System Settings → Privacy & Security → Screen Recording
Status
Always Required for previews

See also Recording indicator and Memory-only window captures.

Guided setup

On first launch, setup requests Accessibility and then Screen Recording permission. It detects each grant automatically, then presents Launch at login and Auto-update options. Setup opens again if a required permission is later removed.

Status
Always

See also Startup in the Settings reference.

Memory-only window captures

Window stills remain in memory and are never written to disk. They are kept between switching sessions and associated with the specific window that produced them. Settings are stored separately in the standard macOS preferences file; see Stored settings.

Status
Always

See also Permission revocation and Screen-sharing exclusion.

Permission revocation

Removing Accessibility or Screen Recording permission clears all captured stills immediately. Crossway remains unavailable until the required permission is restored.

Status
Always

Screen lock

Crossway does not capture windows while the Mac is locked. It refreshes its stills after the Mac is unlocked.

Status
Always

See also Background capture.

Recording indicator

macOS shows its purple recording indicator while Crossway captures a still. The indicator remains visible while live previews are running. With live previews off, it appears only during still capture.

Settings
Optional → Previews
Status
Always

See also Live previews.

No telemetry

Crossway contains no analytics, crash reporter, or third-party SDKs. It sends no usage, device, app, window, or shortcut data.

Status
Always

See also The only network request.

Logging

Release builds write nothing to the macOS system log. Window titles and switching activity are not recorded there.

Status
Always

Stored settings

Crossway stores preferences in its standard macOS preferences file: shortcuts, timing, scales, ordering, display choices, optional settings, update schedule, and setup status. It also stores a process identifier used to keep one copy running. The file contains no window stills, titles, or switching history.

Status
Always

Update-check request

A manual or scheduled update check makes one HTTPS request for public release metadata. Crossway adds no user or device identifier. It compares the response with the running version and does not retain the response. Homepage and Donate open URLs in the default browser; Crossway does not fetch those pages.

Status
Always

See also Update checks.

Menu bar and updates

Status menu, startup, update checks, and installation.

Menu bar app

Crossway has no Dock icon or main window. It runs from a menu bar icon and opens a window only for Settings.

Status
Always

Status menu

The status menu contains Settings (⌘ , while Crossway is frontmost), Check for Updates, Homepage, Donate, and Quit Crossway (⌘ Q). Homepage and Donate open in the default browser.

Status
Always

See also Settings.

Update checks

Check for Updates in the menu and Check now in Settings perform an immediate check. The result reports that Crossway is current, identifies an available version and release date, or reports a failed check. Auto-update uses the selected schedule and displays an alert only when a new version is available. Download opens the release in the default browser.

Where
Menu bar → Check for Updates; Settings → General → Startup and updates
Status
Off by default Auto-update is opt-in; manual checks are always available

See also Manual installation and Startup.

Manual installation

Crossway never downloads or installs an update. It installs no update helper, and its update timer runs only while Crossway is running. To update, download the new version in a browser and replace the copy in Applications.

Status
Always

Crossway uses the standard macOS login-item service. It appears in System Settings → General → Login Items and can be disabled there or in Crossway Settings.

Default
On
Settings

Single running copy

Launching Crossway while another copy is running quits the older copy. Only one copy handles the system shortcuts.

Status
Always

Optional Agent Skill

The optional Crossway Agent Skill can install or replace the app when invoked from a compatible local agent. It presents a plan and requests confirmation before changing the installation. The skill is separate from Crossway and adds no helper, unattended update process, or app network access.

Status
Optional Separate from the app
