Keyboard
⌘⇥

Switch apps. Works exactly like the native switcher. Hold a little longer and live previews of the highlighted app's windows appear underneath.

⌘`

Switch windows. Step through the highlighted app's windows and jump straight to the one you want. No trackpad needed.

⌥⇥

See everything. A grid of every open window, with titles and Dock badges.

⌥`

See this app. The same grid, showing just the current app's windows.

These four are only the start. Many more shortcuts work while the switcher is open.

Read Me
  1. Download Crossway.zip and unzip it (double-click).
  2. Drag Crossway.app into your /Applications folder.
  3. Open it. Crossway lives in the menu bar, so you won't see a Dock icon.
  4. Grant the two permissions it asks for in System Settings → Privacy & Security: Accessibility (to take over ⌘Tab and raise the window you pick) and Screen Recording (for the window previews).
  5. That's it. Once both permissions are granted, Crossway finishes setting up on its own.

Always download in a web browser, from this page. Files sent through chat apps get marked by macOS and won't open. If that happens, the fix is on the Troubleshooting page.

Requires macOS 14 (Sonoma) or later, including Sequoia and Tahoe. Runs on Apple Silicon and Intel.

Privacy

Crossway records nothing and uploads nothing.

Nothing is saved to disk except your settings. Window previews live in memory only and are never written anywhere.

The only time Crossway makes a network request is when Check for Updates is pressed. It fetches the latest release info from GitHub. There is no telemetry and there are no background checks.

Every release is signed with an Apple Developer ID certificate and notarized by Apple. Updates are manual: download in your browser and replace the app.
