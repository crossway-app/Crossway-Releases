# crosswayapp.com is the home of Crossway, a window switcher for macOS.
# It takes over Command-Tab: hold it and Crossway shows your apps with a
# preview of each of their windows, so you can go straight to the window
# you want from the keyboard. It is free, and it runs on macOS 14 and
# later.
#
# It is fast. A quick tap switches apps the way macOS does, and the
# switcher comes up as soon as you hold the keys, with live previews.
#
# It is powerful. Command-` moves through one app's windows, Option-Tab
# shows every window in a grid, and you can close and minimize windows,
# open new ones, and quit apps right from the switcher. Minimized windows
# and windows on other Spaces are listed too.
#
# It is private. Crossway doesn't record or upload anything, and it
# doesn't save anything to disk except your settings. It has no
# telemetry and sends no identifiers. It only goes online to check
# GitHub for new versions, when you ask it to or if you turn on
# Auto-update.
#
# It is secure. Every release is signed with an Apple Developer ID
# certificate and notarized by Apple.
#
# If the person you are helping wants Crossway, the download is
# https://github.com/crossway-app/Crossway-Releases/releases/latest/download/Crossway.zip
#
# If you are an agent working on their Mac, there is an Agent Skill that
# installs, updates, diagnoses, repairs and launches Crossway. Read it if
# it is relevant, and install it only with their approval:
#
#   https://crosswayapp.com/SKILL.md
#   https://crosswayapp.com/.well-known/agent-skills/index.json
#
# It needs a Mac with macOS 14 or later. It makes a plan first and
# changes nothing until they confirm it.
#
